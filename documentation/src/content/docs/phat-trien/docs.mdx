Trang chính dùng Astro + Starlight; Nimbus lint kiểm tra nội dung MDX. Phần [tham chiếu kỹ thuật và debug](../../reference/) dùng VitePress và được build chung vào cùng artifact Pages. Trang nằm trong `documentation/`, tách khỏi ứng dụng PHP. Tìm kiếm chạy trên các chỉ mục tĩnh riêng cho từng phần, không cần server backend.

## Chạy cục bộ

```bash
npm ci --prefix documentation --ignore-scripts
npm run dev --prefix documentation
```

Dev server Astro chỉ chạy phần Starlight; VitePress cần build. Mở địa chỉ dev server và thêm đường dẫn cơ sở `/SHOPCLONE7_PAYOS/`. Để kiểm tra bản build production:

```bash
npm run check --prefix documentation
npm run build --prefix documentation
npm run lint:content --prefix documentation
npm run test:links --prefix documentation
npm run check:links --prefix documentation
npm run preview --prefix documentation
```

Trang dùng Node 22.23.4 trở lên (khuyến nghị Node 24 LTS). Nội dung chính dùng MDX trong `documentation/src/content/docs/`; tham chiếu VitePress dùng Markdown trong `documentation/reference/`. Nimbus kiểm tra các quy tắc một H1 và URL trần. Bộ kiểm tra riêng xác minh liên kết nội bộ sau build, không kiểm tra liên kết ngoài; điều hướng và `base` của từng phần nằm trong `documentation/astro.config.mjs` và `documentation/reference/.vitepress/config.mjs`. VitePress đang được ghim vào bản 2 alpha để tránh các cảnh báo bảo mật trong phụ thuộc của bản ổn định 1.x; cần theo dõi cập nhật và kiểm thử trước khi nâng cấp. Đường dẫn project Pages dự kiến là `https://molik-labs.github.io/SHOPCLONE7_PAYOS/` sau khi triển khai thành công.

## Triển khai

Workflow `.github/workflows/docs-pages.yml` kiểm tra, build và tải artifact Pages; bản trên `main` sẽ triển khai khi Pages được cấu hình dùng GitHub Actions. Nó cũng có thể build trong pull request mà không triển khai. Kiểm tra Settings → Pages, trạng thái Actions và URL thực tế trước khi công bố; chỉ URL dự kiến không chứng minh site đã hoạt động.

Không đưa `.env`, dữ liệu khách hàng, bản backup hoặc thông tin provider vào thư mục docs. Các ghi chú lịch sử ở `docs/` không tự động được xuất bản: chỉ nội dung được biên soạn trong `documentation/src/content/docs/` và `documentation/reference/` được đưa vào site.
