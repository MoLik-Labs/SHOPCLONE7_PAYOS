## Bạn đang tìm gì?

<CardGrid>
  <Card title="Cài đặt & cấu hình" icon="rocket">Chuẩn bị môi trường, bản sao database và cấu hình HTTPS trước khi thử nghiệm. [Xem cài đặt](./bat-dau/cai-dat/).</Card>
  <Card title="Vận hành cửa hàng" icon="setting">Kiểm tra giao diện, thanh toán, đối soát và xử lý các trạng thái chưa rõ. [Xem vận hành](./van-hanh/checklist/).</Card>
  <Card title="Tích hợp API" icon="open-book">Đọc dữ liệu và nhập kho với header API key, kèm các giới hạn cần biết. [Xem API](./api/xac-thuc/).</Card>

## Một lộ trình ngắn

<Steps>
1. Đọc [tổng quan](./bat-dau/tong-quan/) để xác định phạm vi và các điều kiện còn thiếu.
2. Thiết lập [môi trường staging](./bat-dau/cai-dat/) bằng dữ liệu thử nghiệm.
3. Xem [checklist vận hành](./van-hanh/checklist/) và kiểm tra từng tích hợp trước khi cân nhắc triển khai.
</Steps>
