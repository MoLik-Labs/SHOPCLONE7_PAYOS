Rules this system encodes

  • Only tokens: no page invents a colour, a spacing value or a font size.
  • No third-party requests, no build step, no JavaScript in the critical path.
  • Every interactive element is reachable by keyboard with a visible focus ring.
  • Motion only when the visitor has not asked for reduced motion.
  • Images carry width/height; the player reserves its own space, so nothing shifts.

Next: pages adopt tokens.css → base.css → components.css and compose these classes. Nothing in the existing client views changes until you ask for it.
