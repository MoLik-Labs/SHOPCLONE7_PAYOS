Tài liệu tích hợp API

Dùng khoá API để lấy sản phẩm và tạo đơn từ hệ thống của bạn. Khoá này thay cho mật khẩu — không chia sẻ và không dán vào mã nguồn công khai.

Khoá API của bạn

Nếu khoá bị lộ, hãy đổi ngay: khoá cũ ngừng hoạt động tức thì và mọi tích hợp phải cập nhật khoá mới.

Đọc dữ liệu

Mọi yêu cầu gửi khoá qua tham số api_key. Kết quả trả về JSON.

Tạo đơn hàng

GET https://shop.orbit.example/api/api.php?apikey=9f4c1d2a7b6e8c05d3a1f9e7b2c4d608&action=create-order&service_id=3&amount=1

apikey
Khoá API ở trên (api_key cũng được chấp nhận)
action
create-order
service_id
ID sản phẩm cần mua (lấy từ danh sách ở trên)
amount
Số lượng cần mua, trong khoảng min–max của sản phẩm
coupon
Mã giảm giá, bỏ trống nếu không có

Yêu cầu tạo đơn làm thay đổi số dư, nên đừng đặt nó trong một liên kết mở sẵn hay gọi lại tự động: mỗi lần gọi thành công là một đơn thật. Hãy lưu order_id và tra cứu bằng get-order-detail khi cần.

Phản hồi thành công

{
    "code": 200,
    "message": "Tạo đơn hàng thành công!",
    "order_id": "JF465f728224ce11",
    "data": "1000040304952|GUTJXYIFPWLHCNDOMBRKVAQESZ\n1000087676467|IVMRLABECWTQYUXHPOFNJDSZGK"
}

Giữ order_id để tra cứu đơn. Hệ thống không gửi lại tài khoản đã bán, nên hãy lưu phản hồi ngay khi nhận. Nếu nhà cung cấp chưa trả đơn trong thời hạn, đơn được hoàn tiền và phản hồi là "code": 201.
